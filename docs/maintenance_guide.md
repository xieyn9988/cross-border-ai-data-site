# 业务人员维护指南

本文档面向**业务人员**，教你如何零门槛维护这个系统。

**你不需要懂 Python，不需要懂 Git。**

---

## 一、打开系统

### 方式 1：双击

双击项目根目录的 `api.bat`，浏览器自动打开 http://localhost:8000/app

### 方式 2：浏览器

直接访问 http://localhost:8000/app

---

## 二、日常使用

### 上传数据

1. 把 CSV 文件拖入上传区
2. 系统自动识别文件列名
3. 展示可用场景（绿色=可用，灰色=不适用）

### 执行分析

1. 勾选需要的场景（可多选）
2. 点击「开始处理」
3. 结果区显示每个场景的状态
4. 点击「下载」保存结果

### 结果文件

- 文件名格式：`{场景名}_{报告名}_{时间戳}.csv`
- 编码：UTF-8-BOM（Excel 可直接打开）
- 列名：中文

## 三、常见问题

### 问题 1：上传后没有可用场景

**原因**：文件列名和系统字段字典不匹配。

**解决**：检查文件表头，可能是：

- 列名有多余空格
- 列名是字段字典里没有的变体
- 文件编码异常

**联系开发者**，往 `config/field_dictionary.yaml` 加同义词。

### 问题 2：场景显示「不适用」

**原因**：缺少该场景需要的某个字段。

**看提示**：场景卡片下方会显示「缺少业务字段：xxx」。

**解决**：如果该字段确实存在，只是叫法不同，联系开发者加同义词。

### 问题 3：处理失败

**原因**：可能是数据格式问题（空值、异常值）。

**解决**：看结果区的错误信息。常见的：

- `缺少必需字段` -- 字段没识别
- `ParserError` -- CSV 格式错乱
- `KeyError` -- 代码引用不存在的列

### 问题 4：结果文件乱码

**原因**：Excel 编码识别问题。

**解决**：用 Excel 打开时选 UTF-8 编码。或改用 WPS / Numbers。

### 问题 5：想改分析参数

**当前**：参数在 `config/scenario_contracts.yaml` 里，需要开发者修改。

**未来**：将支持网页配置面板（无需改 YAML）。

## 四、数据准备建议

### 上传前

- 用 Excel / WPS 打开 CSV，检查表头
- 确认关键列（订单编号、金额等）不为空
- 保存为 UTF-8 编码（避免乱码）

### 不要做

- 改文件后缀（`.csv` → `.txt`）
- 用 Excel 保存成 `.xls` 老格式（编码可能乱）
- 手工删除必需列

## 五、目录说明

| 目录 | 内容 |
|---|---|
| `data/` | 示例数据 |
| `output/uploads/` | 你上传的文件 |
| `output/results/` | 结果文件 |
| `output/logs/` | 日志（出错时看） |
| `config/` | 配置（开发者维护） |

---

## 六、联系开发者

如果遇到「系统无法识别」或「场景报错」，请提供：

1. 上传文件的表头（第一行）
2. 报错截图
3. `output/logs/` 里相关日志
