面试官可能问：

Q1：为什么用 YAML 不用数据库？

A：文件处理器不需要持久化；配置要可版本化、可读、可改。

Q2：字段驱动怎么实现的？

A：字段字典 + 场景契约 + 映射引擎；插件不碰实际列名。

Q3：加一个场景要改几处？

A：3 处（插件 + __init__.py + YAML），前端 / API 自动适配。

Q4：多文件上传怎么处理？

A：每文件独立读列名；按契约匹配；只传匹配的文件给插件。

Q5：为什么不用 MySQL？

A：当前是"上传-处理-下载"模式，无需持久化；未来加历史记录用 SQLite。

Q6：如何保证健壮性？

A：异常分层 + 日志轮转 + 单模块隔离 + 多编码检测 + 去重。

这些回答，比"我会用 Redis"有说服力得多。
